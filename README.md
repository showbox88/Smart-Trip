# Smart Trip | 智能旅行规划

Smart Trip 是一款以用户体验为核心的旅行规划原型应用。本项目深度复刻了现代顶级旅行规划产品的核心交互逻辑，特别是针对**路线行程单 (Itinerary)** 模块的高级编辑功能进行了高还原度的 UI/UX 实现。

## 🌟 核心功能亮点

### 1. 智能仪表盘中心 (Dashboard Hub)
- **多准则动态过滤**：支持按“全部行程”、“进行中”、“计划中”、“已完成”状态实时筛选行程，内置基于日期的自动识别与人工设定双重逻辑。
- **视图切换引擎**：支持在一键之间从**视觉沉浸的网格模式 (Grid View)** 切换至**数据高密度的列表模式 (List View)**。列表模式现已补全完整的编辑与删除菜单。
- **零闪烁局部渲染**：独创的 `Partial DOM Update` 算法，在切换标签或视图时，仅对行程内容区进行“外科手术式”更新，彻底告别全页重刷。
- **真实费用统计**：看板卡片实时汇总显示该行程所有站点的累计支出金额。

### 2. 沉浸式行程详情区 (Itinerary Engine)
- **侧边栏折叠系统**：支持侧边栏一键收起。折叠后显示简洁的天数图标（如 D1, D2），配备 **鼠标跟随底光效果 (Glow Tracking)**——鼠标靠近按钮时泛起柔和的蓝色光晕，选中的天数始终保持常驻底光。光影通过独立渲染层实现，确保永不遮挡按钮。
- **垂直虚线时间轴**：流畅的连续时间轴，精准串联起每一天的行程。
- **极简紧凑布局**：行程卡片全面左对齐，去除了多余留白；分类图标无缝内嵌于卡片内部。
- **动态颜色主题**：每天单独支持自定义主题色，左侧导航、时间轴 Pin 及地图路线同步智能变色。
- **智能重排与自动滚动**：支持拖拽重排时间线卡片，左侧导航站点数实时更新，支持超长列表时的**边缘自动滚动**。
- **安全删除防误触**：全站核心删除操作搭载定制化的确认弹窗，绝不导致屏幕整体变暗或闪烁。

### 3. 自动化交通计算 (Transit Engine)
- **实时路程分析**：智能计算地点间、地点与酒店间的驾车/步行距离与时长。
- **正则解析引擎**：汇总逻辑完美兼容历史字符串数据与新生成的数值数据，确保每日“总时间、总里程”统计真实准确。
- **交通模式与回程控制**：
    - 点击图标即可在 🚗 (驾车) 与 🚶 (步行) 之间无缝切换。
    - **Labeled Switch 系列**：独家定制的宽轨 Switch 开关，将“显示回程 (Return Route)”文字标签直接整合进开关内部，并随滑块动态偏移，提供极致整洁的视觉体验。

### 4. 交互式地点增强 (Rich Location Modals)
- **Google Places 自动填充**：自动捕捉简介、地址、电话、评分及分类。
- **所见即所得编辑器**：支持时间选择、费用追踪、地址/备注编辑。
- **智能地点换图**：集成 Google Places Photo API，支持直接从 Google Maps 获取并更换真实实拍图。

### 5. 智能酒店与住宿管理
- **酒店入住/退房系统**：自动创建 Check-in 和 Check-out 事件。
- **自动住宿区间识别**：在入住与退房之间，系统自动在每天行程的首尾显示“从酒店出发”与“返回酒店”的 UI 提示，并同步计算交通数据。

### 6. 可视化交互地图 (Google Maps Integration)
- **独立按天渲染路线**：系统仅绘制当前选择天的路网，并适配专属主题色。
- **🌙/☀️ 暗色模式切换**：支持日间/夜间地图风格实时切换。

### 7. 全自动国际化与单位定制 (i18n & Customization)
- **多语言引擎**：全站实现基于 JSON 的多语言支持（目前已覆盖 中/英），支持一键无感切换。
- **动态语言检测**：后端 `server.py` 自动扫描 `i18n/` 目录，无需配置即可扩展新语言。
- **单位与货币系统**：支持用户自定义 公里/英里 (KM/MI)、摄氏度/华氏度 (C/F) 以及货币单位。
- **全深度去硬编码**：全站 UI、工具提示、甚至自动生成的系统备注（如入住登记）均已达成 100% 国际化适配。

### 8. 本地持久化与多格式支持
- **Python 数据服务**：配套 `server.py` 提供轻量级 REST API。
- **本地图片直传**：支持从电脑直接上传图片，自动适配模糊底衬确保展示完整。

## 🚀 快速启动

1. **启动后端服务**：
   ```bash
   python server.py
   ```
   服务将在 `http://localhost:8000` 启动。

2. **打开浏览器**：
   访问 `http://localhost:8000`。

3. **推荐体验流程**：
   - 输入名字登录 → 点击 **"+ 新建行程"** 创建行程
   - 在日程底部搜索框输入地点（如"东京塔"）并按回车添加
   - 拖拽卡片重排顺序，点击卡片编辑详情
   - 点击地图右上角 ☀️/🌙 切换地图主题

## 🛠️ 技术栈

- **前端**：Vanilla JavaScript (ES Modules)、HTML5、CSS3
- **后端**：Python 3 (http.server)
- **第三方**：Google Maps JavaScript API、Flatpickr 日历组件
- **数据**：JSON 文件持久化
