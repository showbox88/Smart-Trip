# Smart Trip | 智能旅行规划

Smart Trip 是一款以用户体验为核心的旅行规划原型应用。本项目深度复刻了著名旅行规划产品 Wanderlog 的核心交互逻辑，特别是针对**路线行程单 (Itinerary)** 模块的高级编辑功能进行了高还原度的 UI/UX 实现。

## 🌟 核心功能亮点

### 1. 沉浸式行程时间轴
- **连击时间线**：Wanderlog 风格的垂直虚线时间轴，精准串联起每一天的行程。
- **微缩全能卡片**：每个目的地独享高对比度的毛玻璃效果卡片，包含动态小图、标签化显示的时间/价格、以及紧凑的地址/联系电话。

### 2. 交互式地点增强 (Rich Location Modals)
摒弃了繁琐的页面跳转，所有关于地点的操作皆在当前视图完成：
- **智能数据填充**：通过底部输入框填加新地点（如：Tokyo）时，系统自动捕捉并生成附带**简介、地址、真实电话**的仿真数据卡片。
- **所见即所得编辑器**：点击行程卡片即可展开包含“多媒体占位图”、“时间胶囊选择器”、“费用精算器”的高级编辑器。
- **快捷悬浮窗**：直接点击卡片上的时间或价格胶囊，即刻弹出独立的悬浮配置框，支持 30 分钟刻度的滑动选择以及即时价格更新，无缝保存。

### 3. 可视化交互地图 (Map Mock)
- **动态寻路落图钉**：右侧宽屏展示交互地图。随着左侧行程单的增加，地图会动态打上带有顺序数字标签（1, 2, 3...）的红白色图钉。

## 📂 项目结构

本项目为了保证极致的轻量化和本地无缝预览性能，采用了 **Vanilla HTML / CSS / JS** 进行开发，无任何重型框架依赖。

```
Smat Trip/
├── index.html        # 主入口文件，包含所有的 DOM 结构与 Modal 浮层模板
├── style.css         # 核心样式表，包含了毛玻璃 (Glassmorphism)、排版及动画代码
├── app.js            # 核心业务逻辑，状态持久化 (Mock)、事件绑定、路由切换与 DOM 渲染
└── README.md         # 项目文档
```

## 🚀 快速启动

1. 克隆或下载本项目到本地。
2. 双击 `index.html` 或使用 VS Code 的 Live Server 插件打开。
3. （推荐体验流程）：
   - 点击首页的 **“开始规划”**
   - 随便输入一个名字，进入看板
   - 点击第一个示例行程 **“日本东京之旅 🌸”**
   - 尝试往第 1 天底部输入框键入“东京铁塔”，观察它的即时展现。
   - 点击刚刚添加的卡片上的时间，体验交互。
