# Smart Trip | 智能旅行规划

Smart Trip 是一款以用户体验为核心的旅行规划原型应用。本项目深度复刻了著名旅行规划产品 Wanderlog 的核心交互逻辑，特别是针对**路线行程单 (Itinerary)** 模块的高级编辑功能进行了高还原度的 UI/UX 实现。

## 🌟 核心功能亮点

### 1. 沉浸式行程时间轴
- **连击时间线**：Wanderlog 风格的垂直虚线时间轴，精准串联起每一天的行程。
- **微缩全能卡片**：每个目的地独享高对比度的毛玻璃效果卡片，包含动态小图、标签化显示的时间/价格、以及紧凑的地址/联系电话。
- **智能分类图标**：自动从 Google 地图数据中提取分类（如餐厅、酒店、机场等），并匹配相应的 Emoji 图标（🍴, 🏨, ✈️）。

### 2. 交互式地点增强 (Rich Location Modals)
- **智能数据填充**：搜索并添加地点时，系统自动捕捉并生成附带**简介、地址、真实电话、评分及分类**的仿真数据卡片。
- **所见即所得编辑器**：点击行程卡片即可展开高级编辑器，支持封面图实时搜索、时间精选及费用追踪。
- **极速交互**：
  - **封面图搜索**：支持回车键 (Enter) 触发搜索，预览图双击 (Double Click) 自动保存并关闭。
  - **键盘支持**：搜索框下拉列表支持方向键选择及回车确认。

### 3. 可视化交互地图 (Google Maps Integration)
- **实时落图钉**：右侧宽屏展示 Google 地图。随着行程单的增加，地图会动态打上带有顺序数字标签的 Marker，并自动调整最佳缩放比例。
- **诊断指示器**：地图区域左下角内置“Map Status”状态条，实时反馈地图 API 加载及渲染状态，辅助调试。

### 4. 本地持久化后端
- **Python 数据服务**：配套 `server.py` 提供轻量级 REST API。
- **JSON 数据库**：数据实时存储在 `db.json` 中，支持 Git 同步与多端协作。

## 🚀 快速启动

1. **启动后端服务**：
   在项目根目录运行 `python server.py`（确保安装了 Python 环境）。
2. **打开前端**：
   双击 `index.html` 或使用 VS Code 的 Live Server 插件打开（地址通常为 `http://localhost:8000` 或 `http://127.0.0.1:5500`）。
3. **推荐体验流程**：
   - 点击导航栏 **“开始规划”**，系统将自动创建一个新行程并进入编辑模式。
   - 在日程底部搜索框输入“东京塔”并按回车。
   - 观察卡片生成的图标（如 🏛️）及地图上的 Marker。
   - 编辑行程封面，体验回车搜索与双击选图。
