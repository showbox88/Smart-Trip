# Smart Trip | 智能旅行规划

Smart Trip 是一款以用户体验为核心的旅行规划原型应用。本项目深度复刻了现代顶级旅行规划产品的核心交互逻辑，特别是针对**路线行程单 (Itinerary)** 模块的高级编辑功能进行了高还原度的 UI/UX 实现。

## 🌟 核心功能亮点

### 1. 智能仪表盘中心 (Dashboard Hub)
- **多准则动态过滤**：支持按“进行中”、“计划中”、“已完成”状态实时筛选行程，内置基于日期的自动识别与人工设定双重逻辑。
- **视图切换引擎**：支持在一键之间从**视觉沉浸的网格模式 (Grid View)** 切换至**数据高密度的列表模式 (List View)**，适配不同管理场景。
- **零闪烁局部渲染**：独创的 `Partial DOM Update` 算法，在切换标签或视图时，仅对行程内容区进行“外科手术式”更新，彻底告别全页重刷带来的视觉闪烁。
- **Logo 快捷导航**：全站 Logo 点击即时返回看板，遵循现代主流 Web 交互直觉。

### 1. 沉浸式行程时间轴
- **垂直虚线时间线**：流畅的连续时间轴，精准串联起每一天的行程。
- **极简紧凑布局**：行程卡片（含地点、笔记、预制清单）全面左对齐，去除了多余留白；分类图标无缝内嵌于卡片内部，添加（+）按钮与时间轴实现像素级精准对齐，最大化空间利用率。
- **动态颜色主题**：每天单独支持自定义主题色（如青蓝、橘红），左侧导航、时间轴 Pin 及地图路线同步智能变色。
- **微缩全能卡片**：每个目的地独享紧凑级毛玻璃卡片，包含动态缩略图、标签化的时间/价格、地址/联系电话。
- **智能拖拽排序**：支持拖拽重排时间线卡片，左侧导航站点数实时精准更新。支持超长列表时的**边缘自动滚动 (Auto-scroll)**。
- **安全删除防误触**：全站核心删除操作搭载高度定制化的轻量级确认弹窗 (Lightweight Custom Confirm Modal)，根据鼠标点击位置动态弹出，绝不导致屏幕整体变暗或闪烁。
- **智能节点与计数**：时间轴自动过滤“笔记”与“清单”类型，侧边栏行程数、时间轴节点红点序号、地图图钉数字三端始终保持完美一致的物理站点计数。
- **无缝表单交互**：全面采用无缝自适应多行文本域 (Auto-expanding Textarea)，增删列表、笔记均采用精准 DOM 级局部替换，彻底告别添加/删除节点时的页面全局闪烁。

### 2. 交互式地点增强 (Rich Location Modals)
- **Google Places 自动填充**：搜索并添加地点时，系统自动捕捉简介、地址、电话、评分及分类信息。
- **所见即所得编辑器**：点击行程卡片展开高级编辑器，支持时间选择、费用追踪、地址/备注编辑。
- **智能地点换图**：集成 Google Places Photo API，支持直接从 Google Maps 获取地点的真实实拍图，支持单选高亮与双击快速更换。
- **高级费用管理**：费用弹窗支持全品类图标选择，金额输入框智能聚焦并全选，操作体验极简高效。
- **键盘导航**：搜索下拉列表支持方向键选择及回车确认。

### 3. 智能酒店与住宿管理
- **酒店入住/退房系统**：在行程中添加酒店，系统自动创建 Check-in 和 Check-out 事件。
- **自动住宿区间识别**：在入住与退房之间，系统自动在每天行程的首尾显示“从酒店出发”与“返回酒店”的 UI 提示，无需手动添加重复卡片。
- **动态状态显示**：卡片实时显示入住/退房时间，并通过特定颜色边框（入住绿/退房红）区分，支持多天住宿。

### 4. 自动化交通计算 (Transit Engine)
- **实时路程分析**：智能计算地点与地点、地点与酒店之间的驾车/步行距离与时长，告别盲目规划。
- **交通模式一键切换**：点击图标即可在 🚗 (驾车) 与 🚶 (步行) 之间无缝切换，数据实时重算。
- **多段航段覆盖**：全面覆盖物理站点及自动生成的酒店往返段。

### 5. 可视化交互地图 (Google Maps Integration)
- **独立按天渲染路线**：系统智能识别当前展开的行程天数，**仅绘制当前天**的路网，并适配专属主题色。
- **按需显示回程**：在“返回酒店”处增加切换开关，自主控制地图上是否显示回程闭环，保持路线清爽。
- **全区域点击响应**：定制地图标记支持全区域点击，修复了交互死角。
- **探索与自定义编排**：直接在全图 POI 详情面板中通过下拉菜单将地点 "**+ 添加到指定行程天数**"。
- **🌙/☀️ 暗色模式切换**：支持日间/夜间地图风格实时切换，默认夜间模式。

### 7. 本地持久化与多格式支持
- **Python 数据服务**：配套 `server.py` 提供轻量级 REST API，支持 JSON 数据与物理文件的双重管理。
- **本地图片直传**：支持从电脑直接上传 PNG/JPG/WebP 图片，自动转存至 `uploads/` 目录，告别 Base64 导致的数据库臃肿。
- **兼容性封面算法**：针对不同尺寸和比例的上传图片，采用“高斯模糊底衬 + 原图等比居中 (Contain)”的渲染方案，确保封面展示 100% 完整且不失美感。

## 🚀 快速启动

1. **启动后端服务**：
   ```bash
   python server.py
   ```
   服务将在 `http://localhost:8000` 启动。

2. **打开浏览器**：
   访问 `http://localhost:8000`。

3. **推荐体验流程**：
   - 输入名字登录 → 点击 **"+ 新建行程"** 创建行程
   - 在日程底部搜索框输入地点（如"东京塔"）并按回车添加
   - 拖拽卡片重排顺序，点击卡片编辑详情
   - 点击地图右上角 ☀️/🌙 切换地图主题

## 🛠️ 技术栈

- **前端**：Vanilla JavaScript (ES Modules)、HTML5、CSS3
- **后端**：Python 3 (http.server)
- **第三方**：Google Maps JavaScript API、Flatpickr 日历组件
- **数据**：JSON 文件持久化
