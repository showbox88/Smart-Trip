# 附件卡（Attachment Card）功能规划书

> 场景：在 Stop 卡下挂载各种凭证、资料和链接，出行时一处查看所有相关文件。

---

## 核心理念

行程中往往有大量零散凭证 —— 预购门票截图、酒店确认函 PDF、餐厅预订链接、二维码入场券……
这些东西分散在邮件、截图、浏览器收藏夹里，到了现场手忙脚乱找不到。
**附件卡让每个 Stop 都变成一个随身文件夹。**

---

## 支持的附件类型

| 类型 | 格式 | 典型用途 |
|---|---|---|
| **图片 / 截图** | JPG, PNG, WEBP, GIF | 门票截图、二维码、收据照片 |
| **PDF** | .pdf | 电子票、预订确认函、行程单 |
| **网络链接** | 任意 URL | 景点官网、预约页面、Google Maps 链接 |
| **（扩展）二维码识别** | 从图片自动提取 | 入场二维码快速展示 |

---

## 用户流程

```
打开 Stop 卡
  ↓
点击"添加附件"按钮
  ↓
选择类型：图片 / PDF / 链接
  ↓
  ├── 图片/PDF → 本地文件选取 → 上传 → 显示缩略图/图标
  └── 链接 → 输入/粘贴 URL → 自动抓取预览（标题+图标）
  ↓
附件挂载在 Stop 卡下方
  ↓
出行时点击附件 → 全屏预览 / 打开链接
```

### 附件展示样式

| 类型 | 展示方式 |
|---|---|
| 图片 | 小缩略图 + 文件名，点击全屏预览 |
| PDF | PDF 图标 + 文件名，点击全屏/下载 |
| URL | 网站 favicon + 页面标题 + 域名，点击打开 |

### 全屏预览

- 图片：可缩放查看（适合现场扫二维码）
- PDF：内嵌 PDF 阅读器（或系统默认 PDF 查看器）
- 链接：直接在新标签页打开

## 功能细节

### 添加附件
- 支持拖拽文件到 Stop 卡
- 支持粘贴剪贴板图片（Ctrl+V）
- 单个 Stop 卡附件无数量限制（建议 UI 超过 5 个时折叠）
- 文件大小限制：图片 10MB / PDF 20MB

### 编辑与删除
- 长按或右键附件 → 删除 / 重命名
- 链接附件可编辑 URL 和显示标题

### 链接预览
- 输入 URL 后自动抓取 Open Graph 元数据（title, description, favicon）
- 抓取失败时降级显示纯 URL

### 排序
- 附件默认按添加时间排序
- 支持拖拽调整顺序

## 技术方案

### 存储

| 内容 | 方案 |
|---|---|
| 图片 / PDF 文件 | Supabase Storage，路径：`attachments/{user_id}/{event_id}/{filename}` |
| URL 链接 | 存数据库字段，无需 Storage |
| 链接预览元数据 | 缓存在数据库（title, favicon_url, description） |

### 数据库

新增 `event_attachments` 表：

```sql
event_attachments (
  id           uuid PRIMARY KEY,
  event_id     uuid REFERENCES events(id) ON DELETE CASCADE,
  type         text,           -- 'image' | 'pdf' | 'url'
  title        text,           -- 显示名称
  storage_path text,           -- Supabase Storage 路径（图片/PDF用）
  url          text,           -- 原始 URL（链接用）或 Storage 公开 URL
  favicon_url  text,           -- 链接预览图标
  sort_order   int,
  created_at   timestamptz DEFAULT now()
)
```

### 链接预览抓取

- 用 Supabase Edge Function 代理抓取，避免前端 CORS 问题
- 抓取 `og:title`, `og:image`, `og:description`, `<title>`, `<link rel="icon">`

## 实施优先级

| 优先级 | 功能 |
|---|---|
| **P0** | 图片 / 截图上传 + 缩略图展示 + 全屏预览 |
| **P0** | URL 链接添加 + 显示 + 跳转 |
| **P1** | PDF 上传 + 预览 |
| **P1** | 附件删除 / 重命名 |
| **P2** | URL 链接自动预览（OG 元数据抓取） |
| **P2** | 剪贴板粘贴图片（Ctrl+V） |
| **P2** | 拖拽调整附件顺序 |
| **P3** | 二维码从图片自动识别并高亮展示 |

---

## 边界情况

| 情况 | 处理 |
|---|---|
| 上传失败 | 显示错误提示，保留本地预览，支持重试 |
| 链接无法预览 | 降级显示纯 URL，不影响保存 |
| PDF 无法内嵌预览 | 提供下载按钮 |
| 删除 Stop 卡 | 级联删除所有附件文件（Storage + 数据库） |
| 离线访问 | P3 考虑：图片/PDF 可选缓存到本地 |
