# 悠闲模式（Wandering Mode）功能规划书

> 场景：旅行结束回家后，通过导入照片反推行程，在地图上完成归类整理。

---

## 核心理念

传统行程 App 是"先规划后旅行"，悠闲模式反过来 —— **先随意玩，回家后用照片重建行程**。
用户不需要在旅途中记录任何东西，只需要正常拍照，回家后导入，地图自动帮你还原去过哪里。

---

## 用户流程

```
导入照片
  ↓
地图视图：照片缩略图按 GPS 分布在地图上
  ↓
用户单选 / 多选照片
  ↓
指定地点（三种方式）
  ↓
生成 / 更新 Stop 卡（event）
  ↓
照片状态变更（隐藏 / 点标记 / 暗灰）
  ↓
重复直到所有照片归类完毕
  ↓
Smart Trip 行程视图实时更新
```

---

## 功能详细说明

### 1. 照片导入

- 支持批量导入本地照片（手机同步 / 文件夹选取）
- 读取每张照片的 EXIF 数据：
  - `GPSLatitude` / `GPSLongitude` — 用于地图定位
  - `DateTimeOriginal` — 用于 event 日期
- 无 GPS 的照片单独列出（提示用户手动归类）

---

### 2. 地图视图

- 地图初始化以照片群的中心/聚合点为默认视角
- 照片以**缩略图**形式显示在对应 GPS 坐标上
- **视口动态加载**：仅渲染当前地图可视范围内的照片，随缩放/平移实时更新（防止大量照片同时渲染卡顿）
- 支持**滚轮缩放**
- 照片重叠时自动聚合（cluster），展开后可单独选取

---

### 3. 照片选择

- **单选**：点击单张缩略图
- **多选**：按住 Shift/Ctrl 点击，或框选（拖拽矩形范围）
- 已选中照片高亮显示（边框或遮罩）
- 选中后出现归类操作面板

---

### 4. 地点归类（三种方式）

选好照片后，指定这些照片属于哪个地点：

| 方式 | 说明 |
|---|---|
| **点击地图** | 直接点击地图上任意位置，生成坐标地点 |
| **附近商家推荐** | 基于选中照片的 GPS 中心，调用 Google Places Nearby Search，列出半径范围内的候选商家供选择 |
| **搜索地点** | 手动输入地点名称搜索（Google Places Search） |

归类后：
- 创建一个新的 **Stop 卡（event）**，或合并到已有的同地点 Stop 卡
- Stop 卡日期取照片 EXIF 的 `DateTimeOriginal`
- Stop 卡自动关联这批照片

---

### 5. 归类后照片状态

归类完成的照片可选三种显示状态（用户可自由切换）：

| 状态 | 视觉 | 说明 |
|---|---|---|
| **隐藏** | 从地图上消失 | 清爽，适合归类完毕后 |
| **点标记** | 小圆点，无缩略图 | 保留位置感，不占视觉空间 |
| **暗灰** | 缩略图变灰半透明 | 仍可见，方便对比未归类照片 |

所有已归类照片无论什么状态，均可**重新点击选中，修改归类或重新编辑**。

---

### 6. 实时同步到 Smart Trip

- 每次归类操作（创建/修改 Stop 卡）立即同步到 Smart Trip 行程数据
- Smart Trip 行程视图实时更新（无需手动刷新）
- 同步内容包括：Stop 标题、地点坐标、关联照片、日期

## 技术方案

### 前端

| 功能 | 方案 |
|---|---|
| EXIF 读取 | `exifr` 库（纯前端，支持 GPS + 日期） |
| 地图渲染 | Google Maps JavaScript API |
| 照片缩略图叠加 | Google Maps Custom Overlay 或 `OverlayView` |
| 视口动态加载 | 监听 `bounds_changed` 事件，过滤当前视口内坐标 |
| 照片聚合 | `@googlemaps/markerclusterer` |
| 附近商家搜索 | Google Places Nearby Search API |

### 后端 / 数据

| 功能 | 方案 |
|---|---|
| 照片存储 | Supabase Storage（已有） |
| Stop 卡数据 | 复用现有 events 表 |
| 照片归类状态 | events 表关联 photos，或新增 `photo_events` 关联表 |
| 实时同步 | Supabase Realtime 或前端 state 直接更新 |

## 边界情况处理

| 情况 | 处理方式 |
|---|---|
| 照片无 GPS | 单独列在"未定位照片"区域，支持手动拖拽到地图或搜索归类 |
| 多张照片时间跨度大 | 按日期分组显示，提示用户是否创建多个 trip |
| 同一地点多次拍照 | 自动聚合到同一 Stop 卡，照片数量叠加 |
| 用户误操作 | 支持撤销（Ctrl+Z）最后一次归类操作 |

---

## 实施优先级

1. **P0** — EXIF 读取 + 地图缩略图展示
2. **P0** — 单/多选照片 + 附近商家推荐归类
3. **P1** — 照片归类后状态切换（隐藏/点/暗灰）
4. **P1** — 实时同步到 Smart Trip 行程
5. **P2** — 无 GPS 照片处理
6. **P2** — 撤销操作
7. **P3** — 照片聚合（cluster）优化
